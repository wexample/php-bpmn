## Introduction

BPMN 2.0 in plain PHP, with no framework: a typed model of processes, read from and written to the XML other tools exchange — bpmn.io, Camunda Modeler, Signavio —, built in code, checked, and walked path by path.

It runs nothing itself: `wexample/symfony-bpmn` turns a process into a Symfony workflow and runs it. What is here is what both need — and what a drawing tool needs too.

```bash
composer require wexample/php-bpmn
```
